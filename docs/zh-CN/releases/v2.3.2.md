# Kaname 2.3.2

[English](../en/releases/v2.3.2.md) · [中文](v2.3.2.md)

一次文档发布，外加一个界面修复。除了那排 chips，行为没有变化。

## 亮点

- **文档变成逐页双语。** `docs/en/` 与 `docs/zh-CN/` 现在装着同样的 16 个文件名，每一页开头都有一行语言切换。这 16 篇里 8 篇原本是英文、7 篇原本就是中文，所以这不是单向翻译：两个方向合计写了约 4,200 行。发布说明也搬进了同一棵树（`docs/en/releases/` 与 `docs/zh-CN/releases/`），`publish_release.sh` 读英文那份。
- **标题栏的修饰键 chips 跟着列表一起亮。** 按住修饰键收窄面板时，行内 chord 的字符亮了，而标题栏那排 chip 只是从灰变亮一点点——因为 chips 与行内键读的是两处不同的状态。现在两边都读 `pending.effective`；点选出来的 tick 保留更厚的填充与描边，所以"钉住"看起来仍然和"正按着"不同。
- 每一页两半之间的一致性是被**量**出来的，不是假设的：标题数、表行数、代码围栏数与链接数两边各算一遍再比对。

## 安装

```
brew tap suliveevil/tap
brew install --cask kaname
```

已经装过：

```
brew upgrade --cask kaname
```

这个构建已签名但未经公证，所以 macOS 会在首次启动时以"未验证的开发者"拦下它。打开
**系统设置 → 隐私与安全性**，点 **仍要打开**；或执行
`xattr -dr com.apple.quarantine /Applications/Kaname.app`。被要求时授予 **辅助功能**；
只有在面板不出现时才需要加 **输入监控**。
