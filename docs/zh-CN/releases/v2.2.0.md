# Kaname 2.2.0

[English](../en/releases/v2.2.0.md) · [中文](v2.2.0.md)

首个公开发布。Kaname 是一个菜单栏工具：它通过辅助功能（Accessibility）接口读取最前面那个 App
的菜单栏，把里面的快捷键放进一个浮动的、which-key 式面板里展示，并且能替你执行它们。

## 亮点

- **实时菜单扫描** —— 只要 App 有标准菜单栏就能用：菜单分组、等价键、启用状态、多段组合键
  （`⌘K ⌘C`）与冲突。约 100 条的内置目录覆盖没有标准菜单栏的 App。
- **which-key 收窄** —— 按住修饰键，列表就收窄到那一层并给出下一键的提示行；热键与双击 ⌘ 能
  唤出全部内容。面板会一直开着，直到你完成一个快捷键或按 Esc——没有自动隐藏计时器。
- **全局搜索** —— 一个全局搜索面板（⌃⌥⌘F）覆盖所有正在运行的 App 的快捷键，支持修饰键别名、
  拼音与词首字母。按 Return 会在你选定的那个 App 里执行选中的命令。
- **只在本机** —— 没有统计上报、没有账号、没有后台联网。这个 App 唯一可能发出的网络请求，
  是你手动触发的那次检查更新。

## 2.2.0 新增

- **授权引导条** —— 请求权限而打开某个权限面板时，一条横向引导条会吸附在系统设置窗口右下角
  并跟随该窗口移动。把条上的 Kaname 图标直接拖进权限列表、拨动开关，引导条会确认并自行消失。
  它还会写明"先移除再添加"的顺序，用于清掉被替换的构建留下的陈旧条目。
- 权限向导窗口改为紧凑长条卡片（740×380，原来是 740×540）。
- 系统设置深链现代化（macOS 13+ 标识符），并在 App 运行期间实时检测权限被撤销。
- 状态、存储与面板预算方面的审计修复；438 个单元测试。

## 安装

1. 下载 `Kaname-2.2.0.dmg`，用随附的 `.sha256` 校验
   （`shasum -a 256 Kaname-2.2.0.dmg`）。
2. 打开 DMG，把 **Kaname** 拖进 **应用程序**。
3. 这个构建已签名但未经公证，所以 macOS 会在首次启动时以"未验证的开发者"拦下它。被拦之后，
   打开 **系统设置 → 隐私与安全性**，点 **仍要打开**；或执行
   `xattr -dr com.apple.quarantine /Applications/Kaname.app`。
4. 启动 Kaname，在被要求时授予 **辅助功能** 权限——引导条会带你走完这一步。只有在面板不出现
   时才需要再加 **输入监控**。
