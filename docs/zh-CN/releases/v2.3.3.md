# Kaname 2.3.3

[English](../../en/releases/v2.3.3.md) · [中文](v2.3.3.md)

一次面板行为与可靠性发布：面板在你点击的地方打开、在全屏 App 上保留正确的行，快捷键不会再
在你关掉发起它的那个界面之后才落下，浅色调色板也保持可读。

## 亮点

- **面板在你点击的那个 Space 打开。** 设置、权限窗口、菜单栏的「快捷键面板」项都在当前 Space
  前置，而不是把窗口恢复到某个全屏 App 的 Space。静态 `.statusBar` 面板层级覆盖原生全屏
  Space；「快捷键面板」菜单项也能再次打开面板，不再被跨进程弹窗守卫丢弃。
- **全屏与隐藏的菜单栏保留正确的行。** 菜单栏读不到时——全屏 App、自动隐藏的菜单栏、调度中心——
  面板用那个 App 上一次的扫描顶替（带 **last scan** 徽标），而不是回退到内置目录。没有快捷键
  可重放的行会说明 *menu bar hidden: this item has no shortcut to replay*。
- **后台那个被标成 dialog 的窗口不再挡住面板。** 弹窗守卫现在只读 App 实际所在的那个窗口及其
  附属 sheet，所以 Safari 后台的 Start Page 窗口不再拒绝每一次触发，而真正的 sheet 仍然会挡。
  被拒绝的触发现在会记录是守卫的哪一半投了票。
- **引擎停止后快捷键不会再落下。** 面板的激活交接与行的 chord 重放都作为可取消的任务持有，在
  界面关闭、为设置或权限收起界面、以及停止时取消；注入器把取消当作「什么都没发出」，所以被
  停下的交接不弹任何提示。
- **更能干的面板。** 执行状态点、精确匹配自动执行、失焦关闭；一个点按切换的提示层与可达的修饰键
  chord；以及带自己 tooltip 的 ⇧ chip——点按把 ⇧ 加进过滤器，按 ⇧ 打开提示层。
- **浅色调色板的可读性与 VoiceOver。** 收藏星与警告文字在浅色模式下解析为更深的实测变体
  （星约 3.4:1，警告在白底约 6:1），深色模式沿用系统色；折叠的配置工具卡读作一个按钮，值为
  *Expanded* / *Collapsed*，带切换动作。
- **更稳的启动与退出。** 第二次启动不再抹掉正在运行那份的崩溃哨兵；退出不再卡在卡死的
  `karabiner_cli` 上，并且仍把最后的设置与用量编辑刷到磁盘。

## 安装

```
brew tap suliveevil/tap
brew install --cask kaname
```

已经装过：

```
brew upgrade --cask kaname
```

这个构建已签名但未经公证，所以 macOS 会在首次启动时以"未验证的开发者"拦下它。打开
**系统设置 → 隐私与安全性**，点 **仍要打开**；或执行
`xattr -dr com.apple.quarantine /Applications/Kaname.app`。被要求时授予 **辅助功能**；
只有在面板不出现时才需要加 **输入监控**。
