# Kaname 2.3.2

[English](v2.3.2.md) · [中文](../zh-CN/releases/v2.3.2.md)

A documentation release with one UI fix. No behaviour changed apart from the chips.

## Highlights

- **The docs are bilingual, page for page.** `docs/en/` and `docs/zh-CN/` now hold the same 16 file names and every page opens with a language switch line. Eight pages were English and seven were already Chinese, so this was not a one-way translation: about 4,200 lines were written in both directions. The release notes moved into the same tree at `docs/en/releases/` and `docs/zh-CN/releases/`, and `publish_release.sh` reads the English one.
- **The title-bar modifier chips light up with the list.** A held key that narrows the panel lit the glyphs inside each row but left the chip in the header only slightly brighter, because the chips and the rows were reading two different pieces of state. Both read `pending.effective` now; a clicked tick keeps its stronger fill and outline, so "sticky" still looks different from "down right now".
- Parity between the halves of every page is measured, not assumed: heading count, table rows, code fences and links are counted on both and compared.

## Install

```
brew tap suliveevil/tap
brew install --cask kaname
```

Already installed:

```
brew upgrade --cask kaname
```

The build is signed but not notarized, so macOS blocks the first launch with an
"unverified developer" notice: open **System Settings → Privacy & Security**, click
**Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Kaname.app`.
Grant **Accessibility** when asked; add **Input Monitoring** only if the panel does not
appear.
