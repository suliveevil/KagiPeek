# Kaname 2.3.3

[English](v2.3.3.md) · [中文](../../zh-CN/releases/v2.3.3.md)

A panel-behaviour and reliability release: the panel opens where you ask and keeps the right
rows over full-screen apps, a shortcut can no longer fire after you close the surface that
launched it, and the light palette stays legible.

## Highlights

- **The panel opens on the Space you clicked from.** Settings, the permission window and the
  menu bar's Shortcut Panel item all order front on the active Space instead of restoring a
  window onto a full-screen app's Space. A static `.statusBar` panel level covers native
  full-screen Spaces, and the Shortcut Panel menu item opens the panel again rather than
  being dropped by the cross-process popup guard.
- **Full-screen and hidden menu bars keep the right rows.** When the menu bar cannot be read
  — a full-screen app, an auto-hidden bar, Mission Control — the panel stands in that app's
  last scan (badged **last scan**) instead of falling back to the built-in catalog. A row
  with no shortcut to replay says *menu bar hidden: this item has no shortcut to replay*.
- **A background window labelled a dialog no longer blocks the panel.** The popup guard now
  reads only the window the app is actually in, plus its attached sheet, so Safari's
  background Start Page window no longer refuses every trigger while a real sheet still
  blocks. A refused trigger now logs which half of the guard voted.
- **A shortcut can no longer land after the engine stops.** The palette's activation
  hand-off and a row's chord replay are held as cancellable tasks and cancelled when the
  surface closes, when surfaces are dismissed for Settings or permissions, and on stop; the
  injector treats cancellation as "nothing posted", so a stopped hand-off shows no toast.
- **A more capable panel.** Execution status dots, exact-match auto-run and focus-loss
  dismissal; a tap-toggled hint layer with reachable modifier chords; and a ⇧ chip with its
  own tooltip — click to add ⇧ to the filter, press ⇧ to open the hint layer.
- **Light-palette legibility and VoiceOver.** The favourite star and warning text resolve to
  a darker measured variant in light mode (star ~3.4:1, warning ~6:1 on white) and keep the
  system colour in dark mode; a folded config-tool card reads as a button valued *Expanded*
  / *Collapsed* with a toggle action.
- **Steadier launch and quit.** A second launch no longer erases the running copy's crash
  sentinel; quitting no longer hangs on a stuck `karabiner_cli` and still flushes the last
  settings and usage edits to disk.

## Install

```
brew tap suliveevil/tap
brew install --cask kaname
```

Already installed:

```
brew upgrade --cask kaname
```

The build is signed but not notarized, so macOS blocks the first launch with an
"unverified developer" notice: open **System Settings → Privacy & Security**, click
**Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Kaname.app`.
Grant **Accessibility** when asked; add **Input Monitoring** only if the panel does not
appear.
