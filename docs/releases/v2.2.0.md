# KagiPeek 2.2.0

First public release. KagiPeek is a menu bar utility that reads the frontmost app's menu
bar through the Accessibility API and shows its shortcuts in a floating, which-key style
panel — and can run them for you.

## Highlights

- **Live menu scanning** — any app with a standard menu bar works: menu grouping, key
  equivalents, enabled state, chords (`⌘K ⌘C`), and conflicts. A ~100-entry built-in
  catalog covers apps without a standard menu bar.
- **Which-key narrowing** — hold modifiers and the list narrows to that level with
  next-key rows; the hotkey and double-tap ⌘ summon everything. The panel stays open
  until you finish a shortcut or press Esc — there is no auto-hide timer.
- **Search everything** — a global search palette (⌃⌥⌘F) over every running app's
  shortcuts, with modifier aliases, pinyin, and word initials. Return runs the selected
  command in the app you picked.
- **Local only** — no analytics, no accounts, no background network. The single network
  request the app can make is the manual update check.

## New in 2.2.0

- **Drag-guide bar for permission grants** — when a request opens a permission pane, a
  horizontal bar anchors itself under the System Settings window's bottom-right corner
  and follows that window. Drag the KagiPeek icon from the bar straight into the
  permission list, flip the toggle, and the bar confirms and dismisses itself. It also
  spells out the remove-then-add order that clears stale entries after a replaced build.
- Compact strip cards in the permission guide window (740×380 instead of 740×540).
- Modernized System Settings deep links (macOS 13+ identifiers) and live detection of
  permission revocations while the app runs.
- Audit fixes across state, storage, and panel budgeting; 438 unit tests.

## Install

1. Download `KagiPeek-2.2.0.dmg` and verify it against the published `.sha256`
   (`shasum -a 256 KagiPeek-2.2.0.dmg`).
2. Open the DMG and drag **KagiPeek** into **Applications**.
3. This build is signed but not notarized, so macOS blocks the first launch with an
   "unverified developer" notice. After the block, open
   **System Settings → Privacy & Security** and click **Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/KagiPeek.app`.
4. Launch KagiPeek and grant **Accessibility** when asked — the drag-guide bar walks you
   through it. Add **Input Monitoring** only if the panel does not appear.
