# KagiPeek 2.2.0 — one row contract, a title bar that fits, which-key narrowing

> **Draft.** This note describes the release as it stands on `feat/v2.2`. The checksum at the
> bottom belongs to the last local build and must be regenerated (the build now writes
> `build/KagiPeek-<version>.dmg.sha256`) before the release is published.

## Highlights

- **A held modifier narrows the panel; a hotkey does not.** Long-pressing ⌃/⌥/⌘ seeds the
  prefix with those modifiers, so holding ⌘ shows the ⌘ set with next-key rows (C, ⇧S, …),
  which-key style. The hotkey (⌃⌥⌘K) and double-tap ⌘ summon it with an empty prefix, where
  every row is a complete combination. Modifier changes while the panel is open narrow or widen
  it live, and releasing everything widens it back — the panel stays open either way. Holding ⇧
  alone does not narrow, so the list is never empty.
- **One row contract for two surfaces.** The panel and the browser window's list share two
  recorded keys: the run key (↩) closes the surface and replays that row's chord into the app
  that should receive it; the copy key (⌘↩) only writes it to the clipboard. Both are recorded
  under **Settings → General → Row actions**, next to **Keep the browser open after running**,
  and the footer hint renders the keys you actually chose.
- **The browser list is live.** Hover selects, a click runs, ↑/↓ walk the list, the row keys run
  and copy, Esc closes — and an active Chinese input method keeps ↑↓ and Return.
- **A title bar that fits.** Three densities measured from the panel width, so the settings and
  close buttons stay reachable in a one-column panel. The old fixed-width search field used to
  push them out of the panel, where they could not be clicked at all.
- **A permission guide, after Thaw's design.** First launch opens a dedicated window with one
  card per permission: what it is for, Required/Optional, a live status, and a Grant button that
  fires the system prompt **and** opens the exact System Settings pane. A poll flips the card to
  a green "Permission granted" and brings the window forward; the KagiPeek icon can also be
  dragged straight into the Accessibility list.
- **Diagnostics you can attach to a bug report.** **Settings → About → Export diagnostics…**
  writes one JSON report: permissions, listener state, the scan result, your settings, and the
  command that prints the matching log lines. The same report is written by
  `KAGIPEEK_SELFTEST=1`, which now works while the app is already running.

## Fixes worth knowing about

- Esc closes the panel with or without modifiers. ⌫ still backs out one chord stroke, and only
  with no other modifier held, so ⌘⌫ stays an ordinary shortcut.
- Switching to another app or another Space closes the panel; summon it again for the new app.
- **KagiPeek no longer mistakes itself for the frontmost app.** Opening the search palette, the
  browser window or Settings activated the app, and the catalog was then rescanned from its own
  menu bar — the panel fell back to the built-in catalog and the browser window renamed itself
  "KagiPeek".
- Nothing is injected while you browse; running a row injects that one chord and finishes.
- The two "Execute menu commands" switches are gone. Neither had controlled anything since rows
  started replaying their chord, and one of them told users Return copies while it ran.

## Install

Requirements: macOS 14.0 Sonoma or later. Bundle identifier, storage location and signing
behaviour are unchanged from 2.1.0.

Download `KagiPeek-2.2.0.dmg`, or build from source:

```sh
git clone https://github.com/suliveevil/KagiPeek.git
cd KagiPeek
./scripts/install.sh
```

> This build is **not notarized** (no Developer ID certificate on the build machine).
> If Gatekeeper complains: `xattr -dr com.apple.quarantine /Applications/KagiPeek.app`.

## SHA-256

Regenerate before publishing:

```sh
shasum -a 256 build/KagiPeek-2.2.0.dmg
```

## Upgrade notes

- Holding modifiers to summon the panel narrows it; releasing them widens it again.
- The row keys are recorded bindings now. If you had a habit of pressing Return expecting a
  copy, use ⌘Return — or record whichever pair you prefer.
- The dead "Execute menu commands" switches are gone from Settings. Existing settings files
  still decode: the keys are simply dropped on the next save.
- Settings, per-app statistics and the data folder carry over unchanged.
