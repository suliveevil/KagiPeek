# KagiPeek 2.1.0 — a panel that waits for you

Nine fixes from real use: the panel is now persistent and reacts to the shortcut you press,
search understands pinyin and modifier abbreviations, the panel can cover the window, and
statistics are per app and survive reinstalls.

## Highlights

- **The panel waits.** Trigger keys (hold modifiers, double-tap ⌘, the global hotkey) are no
  longer treated as a prefix. The panel lists every shortcut of the frontmost app and stays
  until you either finish a shortcut — which is highlighted, then passed through to the app —
  or press Esc. The auto-hide delay is gone.
- **Progressive highlighting.** Holding ⌘ lights up every row that starts with ⌘; adding ⇧
  narrows the glow; completing a shortcut highlights its description for a moment before the
  panel closes. Row selection (↑↓) is a separate visual state.
- **Hyper keys work.** Hotkeys with three or more modifiers accept a superset of modifiers,
  so Karabiner-style hyper (⌃⌥⇧⌘) + K/F trigger the panel and search correctly.
- **Smarter search.** Space-separated, order-independent terms (`com op x` = `op cm x` = ⌘⌥X),
  `+` as a separator, modifier aliases (com/cmd, op/opt/alt, ct/ctl, sh/sft and their symbols),
  full pinyin and pinyin initials for Chinese titles (`jq` → 剪切), and Latin word initials
  (`fs` → Find Similar).
- **Panel placement options.** Cover the front window (default, screen-centred and guaranteed
  larger than the window in both dimensions), fixed size with editable width/height, fill the
  screen, or the old "beside the window".
- **Per-app statistics, durable storage.** Settings and usage now live in
  `~/Library/Application Support/KagiPeek/` as atomic JSON files, with corrupt files preserved
  for inspection. Statistics are grouped by app in Settings → Ranking, and reinstalling the app
  no longer risks the data.
- **Permission help.** "Request" now opens the relevant System Settings pane as well, and the
  app icon in Settings is a real drag source you can drop into the Accessibility list.
- **A dedicated About tab.** Version, build, system, update check, data folder, repository,
  licence, and live diagnostics (permissions, listener, menu item count).
- **One panel at a time.** Opening search closes the panel and vice versa; a new global
  hotkey (⌃⌥⌘S by default) swaps between them.

## Install

Requirements: macOS 14.0 Sonoma or later. Bundle identifier and signing behaviour are
unchanged from 2.0.0.

Download `KagiPeek-2.1.0.dmg` from the release assets, or build from source:

```sh
git clone https://github.com/suliveevil/KagiPeek.git
cd KagiPeek
./scripts/install.sh
```

> This build is **not notarized** (no Developer ID certificate on the build machine).
> If Gatekeeper complains: `xattr -dr com.apple.quarantine /Applications/KagiPeek.app`.

## Upgrade notes

- **The auto-hide delay setting was removed.** A panel now stays until a complete shortcut or Esc.
- **The panel no longer narrows while you hold modifiers.** It lists every shortcut and
  highlights the matching rows instead. Completing a shortcut closes the panel and passes the
  keys to the app.
- **Settings moved to Application Support.** The first launch migrates the old UserDefaults
  values automatically; nothing needs to be re-entered.
- **New default placement is "cover the front window".** Switch back to "beside the window" in
  Settings → Appearance if you prefer the old layout.
- A third hotkey (⌃⌥⌘S) is registered for switching between panel and search.
