# KagiPeek 2.0.0 — actionable, cross-app, and a little smarter

v1.2 made the panel read the real menu bar. v2.0 makes it do things.

## Highlights

- **An actionable panel** — pin the panel and drive it from the keyboard: ↑/↓ selects,
  ←/→ pages, ↵ runs, Esc closes. Those keys are consumed by the panel while it is open.
  Clicking a row works too. With *Execute menu commands from the panel* enabled (default off),
  ↵ and clicks press the real menu item through `AXPress`; with it off they copy the
  shortcut instead. The footer and HUD tell you which happened. A pinned panel stays open
  after a row runs, so several commands can be run in a row.
- **System hotkey conflicts** — KagiPeek reads macOS symbolic hotkeys (Spotlight, Mission
  Control, window tiling, …) and flags the ones that collide with the frontmost app's menu
  shortcuts. System shortcuts are read-only: nothing is bound, changed, or remapped.
- **Multi-app browser** — the browser window can scan any running app, not just the
  frontmost one. The live panel still follows whatever is actually in front.
- **Markdown export** — save the sheet you are looking at through a save panel: grouped by
  menu, `Shortcut` / `Action` columns, unavailable items marked.
- **Smart review ranking** — the new default blends context, decayed usage frequency, and a
  gentle boost for shortcuts you used before but have not touched for 30+ days, so forgotten
  commands resurface without outranking the ones you use every hour.
- **Manual update check** — Settings → Ranking → About can ask the GitHub releases API for the
  latest version. Nothing is downloaded or installed, and nothing is polled.

## Install

Requirements: macOS 14.0 Sonoma or later. Bundle identifier is still `com.voltline.kagipeek`,
so a Developer ID-signed upgrade keeps its Accessibility grant; ad-hoc local builds may need
re-approval after a rebuild.

Download `KagiPeek-2.0.0.dmg` from the release assets, or build from source:

```sh
git clone https://github.com/suliveevil/KagiPeek.git
cd KagiPeek
./scripts/install.sh
```

> This build is **not notarized** (no Developer ID certificate on the build machine).
> If Gatekeeper complains: `xattr -dr com.apple.quarantine /Applications/KagiPeek.app`.

## Upgrade notes

- Default sort order changes from *Context, then frequency* to *Smart review*.
- A pinned panel now consumes ↑/↓/←/→/↵/Esc while it is visible.
- Executing menu commands (panel or search) is still opt-in.
- macOS 14.0 minimum and the bundle identifier are unchanged.
